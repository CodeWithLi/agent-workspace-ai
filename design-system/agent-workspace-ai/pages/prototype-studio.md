# Prototype Studio Override

- Treat the page as a dense product workbench, not a marketing surface.
- Keep prototype metadata and device/regeneration controls in one compact header band.
- Use three functional regions on wide screens: screen navigator, framed preview tool, quality/version inspector.
- The preview is the dominant surface. Desktop and mobile frames keep stable dimensions and never widen the page.
- Screen navigation is always visible on desktop and becomes a horizontal, internally scrolling list on phones.
- Quality state uses icon, text and color together. Agent outputs remain collapsed until requested.
- Guided journeys live in the existing inspector: show explicit step progress, highlight only the current executable control, announce wrong actions inline and preserve free exploration outside guided mode.
- Generation dialogs have visible labels, disabled/loading states and preserve user input on request failure.
- At widths below 760px, stack all regions and keep every primary action at least 44px high.
- Follow the master blue/gray enterprise palette; do not introduce AI-purple gradients or decorative effects.
