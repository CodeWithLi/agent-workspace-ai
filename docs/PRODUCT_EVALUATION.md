# 产品可用性评估

## 当前结论

平台已经具备中小研发团队内部试用所需的完整主链路：账号与权限、项目协作、Agent 精准选择和意图路由、连续会话、工具审批、真实 StateGraph 多 Agent 协作、任务落库、混合 RAG、会议/报告/通知、Token 钱包、运行追踪、审计与 Python 管理后台。

## 已验证能力

- 显式 Agent 选择优先，角色点名置信度 0.99，会话内固定 Agent，避免角色漂移。
- 短期上下文限额、滚动摘要和项目 Memory 防止记忆无限增长。
- BM25 稀疏召回、embedding 稠密召回、Milvus ANN、融合重排、阈值和引用。
- Agent 请求 ID、运行记录、原子预扣、失败退款、审批行锁、并发租约和长任务续期。
- 同项目工作流互斥、暂停/继续、任务幂等和报告持久化。
- Agent 间只传递必要的结构化状态，报告节点排除重复消息和文档，控制上下文增长。
- 运行追踪可按时间、项目和状态分析端到端 P95、Token、预估成本、Agent 延迟与节点瓶颈，并下钻到排队、并行分支、人工等待、模型调用和事件日志。
- 跨运行基线对比可按 Agent 角色和节点/分支定位模型切换后的耗时、Token、成本及结果退化，并支持可分享的深链恢复。
- 可热更新 SLO 覆盖成功率、P95 耗时和单次平均成本，显示错误预算，并用按项目隔离的 MAD 历史基线检测异常运行和直接下钻。
- 异常运行可自动转为持久化告警，支持待确认、处理中、已解决状态，批量确认、解决说明、站内/可选邮件通知和完整审计轨迹。
- 管理员全局汇总与成员本人范围隔离已经验证；追踪只公开运行元数据，不暴露 Prompt、人工反馈、工作流状态正文或产物内容。
- Vue 用户工作台与独立 Python 管理后台均可操作核心管理能力。

## 适用范围

适合企业内部需求分析、项目启动、方案评审、任务拆解、测试设计和知识问答。固定 Token 价格用于成本配额和产品验证，不等于供应商实际 token 数；模拟充值不连接支付渠道。

## 上线前外部条件

- 在具有 Docker 的主机完成 PostgreSQL、Redis、Milvus、MinIO 全栈容器验收和备份恢复演练。
- 配置真实 LLM/Embedding 密钥、SMTP、HTTPS、独立强随机 `SECRET_KEY` 和企业管理员邮箱。
- 接入集中日志、指标告警与数据库慢查询监控，并按实际模型账单校准固定 Token 价格。

## 后续高价值增强

1. 企业 SSO/LDAP、组织与租户隔离。
2. 在已有持久化告警闭环之上增加 Webhook/飞书/钉钉路由、升级策略和容量预测。
3. Prompt/Agent 版本发布、A/B 评测、答案质量评分和回归数据集。
4. 真实支付、发票、套餐、月度配额和供应商 usage 对账。
5. Webhook、飞书/钉钉/企业微信通知及外部工单同步。
