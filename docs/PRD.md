# 产品需求文档

## 产品定位

Agent Workspace AI 是一个基于多 Agent 协作的 AI 项目管理平台，模拟虚拟 AI 软件研发团队，帮助用户完成从需求到测试的研发前置工作。

## 目标用户

- 创业团队负责人
- 产品经理
- 技术负责人
- 中小团队研发管理者

## 核心目标

- 降低项目启动阶段的信息整理成本。
- 将需求分析、架构设计、任务拆解、测试计划沉淀为项目资产。
- 通过企业知识库为 Agent 提供上下文增强能力。

## 功能范围

- 用户系统：注册、登录、JWT 认证、用户信息。
- 项目空间：创建项目、查看项目详情、任务列表。
- AI 员工：产品经理、项目经理、架构师、测试工程师、会议纪要员、知识库管理员、通知秘书、运营分析师。
- AI 聊天：选择 Agent 后进行对话，支持流式输出。
- LangGraph 工作流：按需求分析、产品、架构、项目管理、测试、报告顺序执行。
- 知识库：上传 PDF、Word、Markdown，解析后检索并生成回答。
- 执行治理：Agent 配置、工具白名单、人工审批、用户权限和审计日志。
- 协作触达：站内通知、SMTP 邮件、定时发送和失败重试。

## 页面规划

- 登录页面
- 工作台
- 项目空间页面
- AI 员工聊天页面
- 知识库页面
- 任务看板、会议中心、项目报告、通知中心
- Agent 配置、用户权限、系统设置和审计日志
